# Kairo

**Confidence-building as daily missions, not another feed to scroll.**

Self-development apps fail in a specific way: they hand you content when what
you needed was a task. You read about confidence instead of doing the thing that
builds it.

Kairo assigns **one concrete daily challenge** and tracks the streak. Every
screen ends in an action.

**Live:** [kairo-black.vercel.app](https://kairo-black.vercel.app/)

## What it does

- Daily social-growth missions
- Progress and streak tracking
- Gamified levelling
- Focused, single-task screens — one thing at a time

## The design

A mission-based progression model rather than a content feed. The loop is
**do-the-thing**, not read-about-the-thing. That constraint decided the whole
interface: if a screen can be scrolled past without acting, it doesn't belong.

## Built with

React · Tailwind CSS · progress tracking
